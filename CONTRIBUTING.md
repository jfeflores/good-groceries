# Contributing

Contributions that improve product accuracy, accessibility, privacy, retailer resilience, or test coverage are welcome.

## Before Opening a Pull Request

1. Keep food-tier rationale separate from certification and production claims.
2. Cite credible government, certification-body, manufacturer-label, or first-party retailer sources.
3. Do not add postal codes, store identifiers, location-bound retailer URLs, account data, credentials, or personal notes.
4. Do not present retailer or manufacturer marketing language as independent certification.
5. Run the full validation commands documented in `README.md`.

Product prices and availability change frequently. Prefer conservative wording, preserve the last verified timestamp, and do not silently replace verified data after a temporary retailer error.
